# Meal Mate – Food Discovery Platform

Meal Mate is a responsive food discovery web application focused on making food browsing simple and interactive.

## Features

- Browse food-related content through an interactive interface
- Responsive layouts for different screen sizes
- Dynamic user interface interactions using JavaScript
- Structured layouts using CSS Flexbox and Grid
- User-friendly navigation and browsing experience

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- CSS Flexbox
- CSS Grid

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/kunalrai23/MealMate.git
   ```

2. Open the project folder.
3. Open `index.html` in your web browser.

No additional installation is required.
